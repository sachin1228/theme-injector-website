This build is unsigned. We don’t pay for a code-signing certificate, so Windows will treat it as an unknown publisher the first time. One-time approval is all it needs — here’s exactly how.

First run on Windows

  1. Keep the file. Your browser may say the .exe “isn’t commonly downloaded” — open the downloads bar and click Keep, then Keep anyway if asked.
  2. Run the installer. The blue “Windows protected your PC” screen appears — click More info, then Run anyway.

This build is unsigned. macOS blocks apps it can’t verify, and this one isn’t notarized (that needs a paid Apple Developer account). A 30-second approval gets it running — here’s exactly how.

First launch on macOS

  1. Install it. Open the .dmg and drag Theme Injector into your Applications folder.
  2. Approve it once. Try to open it — macOS blocks it with “Apple cannot check it for malicious software”. Then open System Settings → Privacy & Security, scroll down and click Open Anyway next to the Theme Injector message.Older macOS: right-click the app in Applications → Open → Open.
  3. Seeing “Theme Injector is damaged”? That’s just the quarantine flag on unsigned apps — not a real problem. Run this once in Terminal, then open the app again:
    xattr -cr "/Applications/Theme Injector.app"
